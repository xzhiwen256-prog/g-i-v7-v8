## 客户首次操作

1. 先退出游戏及其他版本的控制器，双击“开始.cmd”。
2. 阅读并明确同意证书 / 用户态驱动安装，等待复制校验，客户自行确认 Windows UAC。
3. V7 打开后填入客户自己的鼠标 DPI / 游戏基础灵敏度；800 / 0.3 只是默认示例。手动开始识别，回到游戏后用 F8 开关跟随。

运行文件会配置到当前用户的 LocalAppData/V7PortableClient，完成并关闭启动器后可以弹出 U 盘。重复运行会校验并复用本地副本，不重复复制全部依赖。配置和控制器都有单实例保护。

若运行库检查失败，启动器提供包内 Microsoft 签名的 VC++ x64 安装入口，需要另外确认；若要求重启，只提示客户重启，不自动重启。不会静默安装或更新显卡驱动。

## 首次安装的重要边界

现有 HIDMaestro 组件会把自签名证书 HIDMaestroTestCert 加入本机 Root / TrustedPublisher，并安装 UMDF 用户态驱动、在 Program Files 写入组件。因此设置了明确同意步骤，不伪装成普通运行库，不静默安装。

不会关闭安全软件、修改 Secure Boot、内存完整性或测试签名，不绕过游戏对虚拟输入的拒绝。首次配置前要求退出游戏；无输入后台成功确认时不打开 V7，并显示错误。

输入后台连接、识别开始、游戏接受移动是不同状态。启动器始终把“游戏接收”保留为未验证，不会凭看到目标就宣称全部可用。CPU 模式需再次确认且不保证实时性。支持范围以 Windows 10/11 x64、匹配显卡及驱动为目标；陌生硬件未实测。

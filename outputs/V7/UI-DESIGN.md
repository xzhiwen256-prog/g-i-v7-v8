## 审计

- 原白色文字叠在紫色选中背景的对比度偏低；小字号注释密集。
- 立即生效的档位/扳机与待应用参数混在一起，容易误解。
- 两个应用按钮文案不同，但实际都提交整组。
- 暂停时“已开启”不能说明当前是否正在输出。
- 展开高级设置和运行详情依赖点击顺序，且形成长文本墙。
- 各种力度/延迟代价必须保留，但不应迫使用户先读技术细节才能操作。

## 五行方向

1. 产品：为 V7 用户提供顺畅的参数设置、运行控制和故障排查入口。
2. 性格：克制、清楚、可靠。
3. 场景：夜间仪表台；深石墨色底，数值和状态比装饰优先。
4. 记忆点：固定的“当前状态 + 参数草稿/代价”区，让用户一直知道现在发生什么。
5. 结构：常用参数、高级设置、运行详情三页；固定底部操作，不将立即动作伪装成草稿。

## 九项处理

1. **间距**：4 px 节奏、统一控件高度、数值输入对齐；范围说明在字段标签下，避免无用留白。
2. **颜色**：背景 #141415，面板 #1C1C1F，字段 #252528；主/次/弱文本 #EDEDED / #B3B3BA / #96969F；选中 #70D3C2 配 #10231F 深字。警告 #E8BC7B、错误 #FFADB4 有语义，不作装饰。
3. **图标**：不增加图标库或装饰 emoji；沿用可理解的文字、加减及原生展开符号。
4. **文案**：统一“应用全部参数”；标出立即应用、未应用、暂停原因与下一步；不宣称“最强”“零延迟”或实战提升。
5. **字体**：保留 Microsoft YaHei UI，标题常规字重；注释至少 9 pt，正文与数字使用一致格式。不下载字体，不仿造网页字体效果。
6. **布局**：三页独立、滚动位置记忆；960×760 默认逻辑尺寸，小窗转单列；导航和底部操作不随内容滚走。
7. **细节**：可见焦点、选择态、隐藏错误字段定位；原生 ttk 一致直角控件，未为圆角引入自绘或新依赖。
8. **视觉**：真实参数和状态就是主体，不增加背景图、伪图表、渐变、发光、营销占位数据。未生成装饰图片。
9. **动效**：不增加动画，避免输入与运行时不必要的重绘；文本仅在显示值变化时更新。没有测量或保证实战性能提升。

## 交互约定

| 行为 | 生效时机 | 说明 |
|---|---|---|
| 切换页面、查看代价、展开说明 | 仅显示 | 保留草稿，不保存、不改变控制状态 |
| 参数字段/算法/定位/协调选项 | 整组应用后 | Return 或“应用全部参数”；非法输入拒绝整组提交 |
| 放弃编辑 / Esc | 恢复显示草稿 | 恢复已应用值，不改变已生效配置 |
| 档位 / 恢复本档 | 立即应用 | 沿用原行为，会暂停跟随并重置其他草稿，旁边明确提示 |
| 自动扳机 | 立即生效 | 放在运行详情，非草稿，不保存开启状态；仍受原门控约束 |
| 开始/停止/跟随/F8 | 原有运行操作 | 没有自动启动，不改安全门控或控制参数 |

Alt+1/2/3 切换三页。下拉框滚轮只滚动界面；Return/Esc 与数值输入一致。主窗口状态由统一只读 presenter 生成；运行轮询不再将暂停/等待覆盖为“并行”。识别失败不显示为就绪，加载线程活着不等于模型已加载完。

所有已知减弱、暂停或延迟代价仍有选项旁的短说明和完整代价区；固定摘要不是“等强度”保证。技术机制可以展开查看，直接使用的后果不会藏在展开项里。
